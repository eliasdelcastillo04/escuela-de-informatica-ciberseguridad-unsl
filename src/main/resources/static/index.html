🔍 Análisis de Código (Antes vs. Después) — UserController.java Mostrar / Ocultar
🔴 Vulnerable (Concatenación SQL) 
String sql = "SELECT id, username, password, role, ssn "
  + "FROM users WHERE username = '" + username + "'";
ResultSet rs = stmt.executeQuery(sql);
🛡️ Remediado (PreparedStatement + Mínimo Privilegio) 
String sql = "SELECT id, username, role FROM users WHERE username = ?";
PreparedStatement ps = conn.prepareStatement(sql);
ps.setString(1, username);
ResultSet rs = ps.executeQuery();

String html = "<h2>¡Bienvenido, " + name + "!</h2>";

String safeName = Encode.forHtml(name);
headers.set("Content-Security-Policy",
