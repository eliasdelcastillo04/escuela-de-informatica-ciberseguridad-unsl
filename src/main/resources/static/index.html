ID Usuario Rol Password (Hash / Plano) SSN (Dato Sensible)

Endpoint: /api/users/search
Auditoría de Código: CWE-89

Inseguro (Vulnerable por Concatenación):

// VULNERABLE: Concatenación directa de parámetro en sentencia SQL
String sql = "SELECT * FROM users WHERE username = '" + username + "'";
ResultSet rs = stmt.executeQuery(sql); // Parser interpreta datos como código

Remediado (PreparedStatement / Parámetros Bind):

String sql = "SELECT id, username, role FROM users WHERE username = ?";
PreparedStatement ps = conn.prepareStatement(sql);
ps.setString(1, username); // El motor SQL trata el parámetro como valor literal

Endpoint que genera una vista HTML interpolando directamente el nombre ingresado.

Visor del Carnet Emitido por el Servidor (Respuesta text/html)
Endpoint: /api/profile/greet
Auditoría de Código: CWE-79

Inseguro (Interpolación cruda en HTML):

// VULNERABLE: Inyección directa de entrada en cuerpo HTML
return ResponseEntity.ok()
    .contentType(MediaType.TEXT_HTML)
    .body("<h1>Bienvenido " + name + "</h1>"); // Browser ejecuta tags arbitrarios

Remediado (Encode.forHtml + Content-Security-Policy):

String safeName = Encode.forHtml(name); // Sanitiza <, >, ", ', &
return ResponseEntity.ok()
    .header("Content-Security-Policy", "default-src 'self'; script-src 'none';")
    .contentType(MediaType.TEXT_HTML)
    .body("<h1>Bienvenido " + safeName + "</h1>");

// VULNERABLE: No se valida si el archivo resuelto queda dentro de baseDir
